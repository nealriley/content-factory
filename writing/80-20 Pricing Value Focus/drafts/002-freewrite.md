the eighty twenty power distribution rule applies to the value a user will receive from your product. This pareto rule is often misunderstood when it comes to how you can define this distribution fo the twenty percent of product value that eighty percent will find useful. Often vendors will be thinking in a very monolithic way when it comes to their pricing, a single model that will apply across the whole of the user base. There are reasons this occurs, sometimes a preference for simplicity is a conscoius choice, but often this is simply because the platform to implement their monetization strategy isnt able to easily account for different modles interoperating with each other. It turns out that the eighty twenty rule applies to cohorts as well as the general population. Interestingly you will often find usage cohorts with user groups that find certain sets of features as their twenty percent of usefuleness and often do not overlap with other groups. These are all optimizations that can be applied to the unique user groups, and either a set of core plans that cover these areas can be priced, or a model of addons to a core set of features can address tehse unique areas.
