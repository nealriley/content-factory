## Content Factory

Writing toolkit and agent framework to take a content idea from research through drafting. Each project lives in its own folder with a `drafts` subfolder for in-progress markdown drafts; supporting research and assets can sit alongside.
Add a `snippets` subfolder per project for tiny reusable ideas/paragraph fragments to recombine into drafts.

### Current project
- `Tokens and Transparency/`: explores transparent AI pricing with drafts under `drafts/` and reusable snippets under `snippets/`.
